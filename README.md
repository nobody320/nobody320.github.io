# nobody320 的个人主页

简洁学术风格的静态个人网站，适配手机与电脑，无需安装依赖或构建。

## 内容编辑

- `index.html`：个人介绍、专业、研究方向、项目入口和联系方式。
- `about-site.html`：建站说明、实现取舍与参考来源。
- `assets/style.css`：配色、排版和移动端样式。
- `assets/main.js`：深浅主题切换、主题记忆和导航状态。
- `assets/favicon.svg`：网站图标。

## GitHub Pages 部署

将此文件夹内的文件上传到公开仓库 `nobody320/nobody320.github.io` 的 `main` 分支。在仓库的 Settings → Pages 中选择 Deploy from a branch，分支选择 `main`，目录选择 `/ (root)`，点击 Save。

部署完成后访问：https://nobody320.github.io

部署方法参考：[GitHub Pages 官方快速入门](https://docs.github.com/en/pages/quickstart)。
