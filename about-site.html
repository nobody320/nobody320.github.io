SITE NOTES / 01

这个网站的设计与实现

建站记录 · HTML / CSS / JavaScript

把个人介绍、项目和学习记录放在一个清晰、轻量、方便维护的空间里。

内容先于装饰

首页首先回答三个问题：我是谁、做过什么、在哪里找到我。专业和研究状态直接展示；项目用简短说明交代用途和实现；学习记录保留独立入口，便于持续整理。

目前唯一展示的项目就是这个网站。未来补充作品时，每个项目都可以沿用“问题、实现、结果、链接”的结构，帮助读者判断内容是否与自己有关。

两种入口，一个身份

GitHub 资料页保持简短，承担自我介绍与链接导航的作用。独立网站承载更完整的项目说明和学习记录。两者使用相同的用户名、配色和身份信息。

实现取舍

  • 原生静态页面：使用 HTML、CSS 与少量 JavaScript，无需安装依赖或运行构建。
  • 阅读优先：米白与墨绿为默认配色，支持深色阅读；限制正文宽度，保留明确的标题层级。
  • 不同屏幕：电脑端使用侧边导航，手机端将导航移到正文上方。
  • 渐进增强：关闭 JavaScript 后仍可阅读全部正文和访问链接；脚本只增强主题切换、年份与导航状态。
  • 可访问性：提供键盘焦点提示、跳至正文入口，并尊重减少动态效果的系统偏好。

参考与启发

第二版参考了以下作者的公开主页，借鉴其信息组织方式，并为当前内容重新设计。

  • Andrej Karpathy：直接介绍个人方向，将经历、教学与作品分开组织。
  • Anthony Fu：通过清晰的项目与写作入口连接个人内容。
  • Sindre Sorhus：简洁的 GitHub 介绍，以及直达作品的入口。

研究方向目前仍在探索中。后续内容将随真实的学习与项目积累更新。
